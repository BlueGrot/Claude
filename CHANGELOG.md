# Feedback Loop — revisions

The revision is shown on the title screen, the pause menu and the end screen (`rev N · date`).
Bump `REV` / `REV_DATE` in `index.html` and add a line here with every change.

r01–r14 were numbered after the fact from snapshots taken during development; each one is
archived in `revisions/` and playable as-is (those builds don't show a revision label).
The time is when the snapshot was taken, so a build someone played sits between its time and the next one's.
